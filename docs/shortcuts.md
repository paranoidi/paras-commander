# Shortcuts

## Design overview

Default navigation mode uses midnight commander style shortcuts. Arrows for navigation, letters for fast fuzzy matching current content. F-keys and keycombinations with Ctrl (C), Alt (M), Shift (S) are used for commands.

Alt (M) key combinations are generally used for altering current view and Ctrl (C) keys are for issuing commands.

Leader key based commands are available via ":" key. Great deal of care has been put so that the letters are same in both cases. Persistent vi/leader key mode can be toggled with ESC. Vi/leader key mode is indicated by yellow border.
