# Default shortcuts avoid Ctrl+Alt combinations

Ctrl+Alt chords proved unreliable across terminals (swallowed by the desktop/terminal or encoded inconsistently), so defaults prefer plain Alt+letter for views and Ctrl+letter for commands, even when the mnemonic is weaker. Users can still bind Ctrl+Alt in `keybindings.toml`. See `keybindings.md` and `recipes/add-keybinding.md`.
