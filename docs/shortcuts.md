# Shortcuts

## Design philosophy

Default mode uses midnight commander inspired shortcuts. Arrows for navigation, letters for fast fuzzy matching current content. F-keys and keycombinations with Ctrl (C), Alt (M), Shift (S) are used for issuing commands and changing views.

Alt (M) key combinations are generally used for altering current view and Ctrl (C) keys are for issuing modifications. Letters use easy to remember mnemonics prioritizing most common usecases over rare (eg. f for find instead of flatten).

Leader key based commands are available via ":" key. Great deal of care has been put so that the letters are same in both cases. Persistent vi/leader key mode can be toggled with ESC. Vi/leader key mode is indicated by yellow border.
